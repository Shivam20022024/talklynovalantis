The live path still isn't built

The guardrail check (guardrail.py) is real and runs today — but only from the post-call webhook. The live, mid-call transfer depends on Bolna exposing a mid-call transfer/function-call tool, which hasn't been confirmed. That's still the first thing to verify.

Tenant isolation was rebuilt, not imported

MediSaarthi has its own auth.py with the same pattern Talkly uses — a hospital is a tenant, every query scoped by hospital_id — but it's fresh code in this repo, not a shared import. No dependency on Talkly at runtime.

RAG grounding isn't built yet

Protocols are stored (protocols collection, including each hospital's red-flag phrase list), but nothing retrieves them into a live Bolna call yet. Until that loop exists, "never diagnoses" is enforced only by what's in the prompt, not by what the agent can actually see.
